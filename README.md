---

## ✨ Signature Technical Features

### 🌌 Immersive 3D Experience
- **Three.js Starfield**: A high-performance WebGL scene featuring morphing constellations and particle systems that respond dynamically to scroll progress and mouse position.
- **GSAP Orchestration**: Complex timeline management for scroll-triggered animations, ensuring smooth transitions even on low-powered devices.

### 🏎️ Performance & UX
- **Lenis Smooth Scroll**: Decoupled scroll events for a buttery-smooth desktop experience.
- **Glassmorphic UI**: Modern CSS implementation utilizing backdrop filters, dynamic gradients, and variable-based design systems.
- **Magnetic Micro-interactions**: A custom-coded cursor logic that enhances user engagement on interactive elements.

### 📄 Integrated Resume Experience
- **Live PDF Preview**: A seamless full-screen resume viewer integrated directly into the UI.
- **Floating Action Button (FAB)**: A premium navigation element for instant access to professional credentials.

## 🛠️ Global Tech Stack

### Frontend Foundations
- **HTML5/SCSS**: Modern semantic structure with advanced CSS architectures.
- **Modern JavaScript**: ESNext features for robust, maintainable logic.
- **Creative Suite**: Three.js (3D), GSAP (Motion), Lenis (Scrolling).

### Full-Stack Ecosystem (Flagship: [Spotless](../Spotless))
- **Next.js 15**: Utilizing App Router, Server Components, and interleaved rendering.
- **NestJS**: Enterprise-grade backend architecture with RxJS and modular dependency injection.
- **Prisma & PostgreSQL**: Type-safe database management and relational modeling.
- **Docker**: Containerized deployment pipelines.

### Local Preview
1. Clone the repository.
2. Serve the directory using a local server (e.g., VS Code Live Server or `npx serve`).
   > **Note**: Three.js requires a server environment to load textures and modules correctly.

- Deployed on **Vercel** with automatic CI/CD pipelines.
- Assets served via global CDN for sub-second load times.
