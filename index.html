ASKVIT (Production-Grade Academic ERP)

Next.jsFastAPIPostgreSQLpgvectorOpenAI

Overview

An enterprise-grade academic ERP built to unify student portals and automate faculty workflows. The project consolidated three fragmented legacy systems into a single, high-performance dashboard.

Architecture

The frontend leverages Next.js for server-side rendering and rapid interactions, while the backend relies on FastAPI for high-throughput, asynchronous API routes. A PostgreSQL database with pgvector was implemented to support complex relational queries alongside vector embeddings.

Key Features

  • Role-based Access Control: Distinct portals for Students, Administrators, and Faculty with strict permission gating.
  • Automated Timetable Generation: An algorithmic slot-based scheduler that prevents resource conflicts.
  • Level-1 Query Automation: An embedded RAG chatbot powered by OpenAI that answers student queries regarding schedules, grades, and policies instantly.

Impact & Metrics

The integration of the RAG chatbot automated 80% of repetitive academic queries, significantly reducing administrative burden. The unified dashboard improved user retention and decreased average task completion time by 60%.

BharatFin – AI Financial Assistant

PythonFastAPILangChainOCRNext.js

Overview

An AI-powered financial assistant designed to democratize portfolio analysis for retail investors, converting complex financial data into conversational insights.

Architecture

The core intelligence is powered by Python and LangChain, exposed via a lightning-fast FastAPI backend. The frontend is built with Next.js to ensure a responsive, app-like user experience. Real-time market data is ingested and cached for zero-delay retrieval.

Key Features

  • Real-time Market Data Ingestion: Continuous syncing with financial APIs to ensure data accuracy.
  • Automated Document Parsing: An advanced OCR engine that instantly extracts key metrics from uploaded financial statements and PDFs.
  • Conversational Portfolio Insights: Users can query their portfolios using natural language, receiving tailored advice and risk assessments.

Impact & Metrics

The platform reduces complex portfolio analysis time by 90% compared to manual spreadsheet tracking. The OCR processing pipeline extracts data securely with near-instant turnaround times, dramatically improving decision-making speed for users.
